# Damilare Osundeyi Portfolio

A responsive static portfolio website for GitHub Pages. It includes the supplied Bike Sales Dashboard screenshot and Freelance Website UI screenshot, plus links to the Figma design.

## Publish with GitHub Pages

1. Sign in to GitHub as `Bigandre-ux`.
2. Create a **public** repository named `damilare-portfolio`.
3. Upload the contents of this folder (upload `index.html`, `README.md`, and the `assets` folder; do not upload the enclosing folder itself).
4. Commit the files to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then Save.
7. After deployment, the site should be available at:
   `https://bigandre-ux.github.io/damilare-portfolio/`

The Figma link will work for visitors only if the Figma file's sharing permissions allow them to view it. The project screenshots are included locally in the website, so the portfolio preview does not depend on Figma access.
